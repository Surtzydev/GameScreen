# GameScreen Settings

Sistema de crosshair personalizado para SA-MP com texturas externas. Controle total de posição, tamanho, cor e sensibilidade. Interface `/gamescreen`. MonetLoader 3.6.0+.

## Funcionalidades

- Crosshair personalizado com texturas
- Oculta o crosshair nativo do jogo
- Ajuste de tamanho e posição do crosshair nativo
- Sensibilidade da tela
- Sensibilidade por arma
- Mecânica de sensibilidade ao mirar/atirar
- Proporções de tela com posições centralizadas
- Ajuste de FOV
- Zoom fixo
- Distância de renderização
- Interface com tema dinâmico
- Tradução PT/EN/ES

## Comandos

- `/gamescreen` - Abre configurações
- `/mcross` - Aba do crosshair
- `/sensa` - Aba de armas

Requer MonetLoader 3.6.0+ e SA-MP 0.3.7
